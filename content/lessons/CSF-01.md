## 程序把数据变成结果

买 3 本笔记本，每本 12 元，你会先拿到单价和数量，再相乘，得到 36 元。写程序，就是把这样的处理步骤表达成计算机可以执行的指令。

**输入 Input**：计算所需的数据。**处理 Processing**：对数据执行的步骤。**输出 Output**：需要得到的结果。

| 输入 | 处理 | 输出 |
| --- | --- | --- |
| 单价 12，数量 3 | 单价 × 数量 | 总价 36 |

输入不一定来自键盘，也可以来自文件、另一个程序，或先写在示例代码里。输出也不一定打印在屏幕上，可以返回给调用者或保存到文件。本课先使用终端显示结果。

```python
unit_price = 12
quantity = 3
total = unit_price * quantity
print(total)
```

前三行准备数据并计算，最后一行把结果显示出来。先不用背术语，试着指出：**这四行里，哪一行真正算出了总价？**

自查答案：第三行；第四行只是显示已得到的结果。

## 赋值和输出是两件事

在 Python 中，`=` 表示赋值 Assignment：先计算右边，再将结果绑定到左边的名字。你可以用这个名字访问对应的值。

| 执行完 | 当前相关值 | 是否显示数值 |
| --- | --- | --- |
| `unit_price = 12` | unit_price 为 12 | 否 |
| `quantity = 3` | quantity 为 3 | 否 |
| `total = unit_price * quantity` | total 为 36 | 否 |
| `print(total)` | total 仍为 36 | 是，36 |

这张表就是最简单的**执行跟踪**：每执行一步，记录一次状态。下一单元会用同样的方法理解循环。

注意，这里讨论保存成文件运行的 Python 脚本。交互式解释器会显示某些表达式的结果，但不能据此认为脚本中每次赋值都会打印结果。

你接触过的 C# 可以完成同一个计算。下面片段放在有效的程序体内：

```csharp
int unitPrice = 12;
int quantity = 3;
int total = unitPrice * quantity;
System.Console.WriteLine(total);
```

`int` 表示这里使用整数，分号用于结束语句。两种写法的共同思路是准备数据、计算、输出。本课只比较这段整数乘法，不代表两种语言所有运算规则都相同。

## 把一个新问题拆成三步

换一个场景：已知矩形长 5、宽 4，要得到面积。

1. 输入是什么？长和宽。
2. 处理规则是什么？长乘以宽。
3. 输出是什么？面积 20。

不要把“做了计算”与“显示了计算结果”混为一谈。下面脚本完成了计算，但没有输出语句：

```python
length = 5
width = 4
area = length * width
```

它运行后不会主动显示 20。加上 `print(area)` 才会显示。相反，一个函数可以把面积返回给调用者，即使没有打印，也有供外部使用的输出结果。

**本课带走的三个判断：**程序表达步骤；数据是步骤处理的对象；赋值、计算和输出的职责不同。
