## 复杂度：计算增长规律，而不只看循环层数

**目标：** 从代码推导执行次数、时间和额外空间。这是从“会写程序”到“能分析算法”的关键一步。默认一次整数比较、数组访问是常数时间，n 是输入规模。

对 `for (i=0; i<n; i++)`，循环体执行 n 次；两个完整嵌套的 n 次循环通常为 Θ(n²)。但如果内层边界取决于外层，必须先数实际次数。

```c
int count = 0;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
        count++;
    }
}
```

执行次数为 0+1+…+(n−1)=n(n−1)/2，因此紧确增长阶为 Θ(n²)，常写时间复杂度 O(n²)。O 是上界；多个上界同时成立时，练习要求选择紧确阶，避免“它也属于 O(n³)”这样的歧义。

如果外层每次翻倍 `i=1; i<n; i*=2`，经过 k 次增长到约 2ᵏ，故轮数为 Θ(log n)。内层每轮做 n 次常数操作，总量为 Θ(n log n)。循环数不是固定答案，更新方式才决定轮数。

空间分析只计算题目指定口径。若仅用几个整型变量，**额外空间**为 O(1)，即使输入数组本身有 n 个元素；递归则需要计入调用栈。递归深度 n 且每层固定大小时，调用栈空间 O(n)，不能仅数函数内声明了几个变量。

**自查：** 两个先后执行的循环，一个 O(n)，一个 O(n²)，总时间是相加后保留主导项 O(n²)，不是相乘成 O(n³)。

## 栈、树与表示：从结构约束排除错误答案

**栈 Stack** 后进先出。给定压栈顺序 1、2、3、4，允许入栈和出栈交错。判断输出序列时按需要压入，只有栈顶能弹出。

例如输出 3、1、2、4：先压入 1、2、3 并弹出 3，栈顶是 2，不能跳过它先弹 1，因此不可能。输出 2、1、4、3 可以按“压 1、2；弹 2、1；压 3、4；弹 4、3”实现。

**二叉树遍历** 用根相对于左右子树的访问位置区分：先序为根—左—右，中序为左—根—右，后序为左—右—根。重建树时还需要结点标签互不相同，不能忽略这一条件。

例：先序 `A B D E C`，中序 `D B E A C`。

1. 先序首项 A 是根；中序中 A 左边 `D B E` 是左子树，右边 C 是右子树。
2. 左子树先序为 `B D E`，根为 B；D、E 分别在 B 左右。
3. 后序得到 `D E B C A`。

对非空二叉树，若度为 0、1、2 的结点数分别是 n₀、n₁、n₂，边数一方面为 n−1，另一方面为 n₁+2n₂。联立 n=n₀+n₁+n₂，得 `n₀=n₂+1`。它适用于二叉树，不要求满二叉树。

**图的表示影响复杂度。** n 个顶点的邻接矩阵需要 n² 个位置，与实际边数无关；邻接表空间为 O(n+e)。查是否存在某条边时，矩阵查表方便，但稀疏图通常浪费空间。

**自查：** 一棵二叉树有 9 个度为 2 的结点，不论有几个度为 1 的结点，叶子数都为 10。

## 二分查找：区间不变量、边界与失败路径

前提是数组按目标比较规则**有序**。本课使用闭区间 `[low, high]`，尚可能包含目标的位置都在区间内。C 的 `int a[]` 是数组参数，`a[mid]` 访问下标 mid；整数除法丢弃小数部分，以下边界均非负。

```c
int binary_search(const int a[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

目标大于 a[mid] 时，mid 本身已经比较过，也不可能是答案，所以设 low=mid+1；目标更小时设 high=mid−1。只写 low=mid 可能导致区间无法缩小而死循环。

查 `[4, 11, 19, 28, 36, 47, 59]` 中的 47：首次 mid=3，比 28 大，区间变为 [4,6]；再次 mid=5，命中 47，共检查两个中间元素。若查 35，依次比较 28、47、36，最终 high<low，返回 −1。

每轮至少把待查规模约减半，最坏时间 O(log n)，迭代实现额外空间 O(1)。同样问题若递归实现，要考虑 O(log n) 调用栈。n=0 时 high=−1，循环直接跳过；n=1 时仍须允许 low==high，所以循环不能无条件改成 `<`。

**等概率成功平均查找长度 ASL**：将每个元素被找到时经历的中间元素比较次数加总，再除以 n。7 个元素形成满的查找判定树时，次数分层为 1 个×1、2 个×2、4 个×3，故 ASL=17/7。不要用最坏次数 3 代替平均值。

本节能应对二分的阅读与填空；堆排序、图算法等更长案例仍需后续专题训练。

## 动态规划：定义状态比记住代码更重要

任务：给一个非空整数数组，找**非空连续子数组**的最大和。连续子数组不能跳着选元素；它与“子序列”不是同一个限制。

设 `ending[i]` 为“必须以 i 位置结尾”的最大连续和。它只有两种选择：从 a[i] 重新开始，或接在最优的 ending[i−1] 后面。因此 `ending[i]=max(a[i], ending[i−1]+a[i])`。全局答案再取所有 ending 的最大值。

对 `[3, -5, 4, 6, -2]`：

| i | a[i] | 以 i 结尾 ending | 到目前的 best |
| --- | --- | --- | --- |
| 0 | 3 | 3 | 3 |
| 1 | -5 | -2 | 3 |
| 2 | 4 | 4 | 4 |
| 3 | 6 | 10 | 10 |
| 4 | -2 | 8 | 10 |

状态只依赖前一步，可以把数组状态压缩成变量。以下假定 n≥1 且所有中间和都在 int 可表示范围内：

```c
int max_subarray(const int a[], int n) {
    int ending = a[0], best = a[0];
    for (int i = 1; i < n; i++) {
        int joined = ending + a[i];
        ending = joined > a[i] ? joined : a[i];
        if (ending > best) best = ending;
    }
    return best;
}
```

`condition ? x : y` 是 C 的条件表达式：条件为真取 x，否则取 y。时间 O(n)，压缩后额外空间 O(1)。若保存全部 ending，则额外空间 O(n)，两种写法不能混写空间结论。

**关键边界：** 若输入全为负数，如 [−7,−2,−5]，结果应为 −2。把 best 初始化为 0 会错误地允许选空子数组。题目如果允许空子数组，则模型改变，初始化才可能不同。

自评时检查四件事：状态含义、转移条件、初值、结果位置。能够解释这些，才说明理解了动态规划，而不只是复述算法名。
