## 考查目标
在题目明确为 C11、给出类型宽度或不依赖宽度的前提下，判断整数提升、常用运算符、短路规则和控制流。遇到越界、除零、无序修改等情形，先判断语义是否有定义，不用某次运行结果代替标准结论。

## 必要概念
C 的对象类型决定表示范围和允许操作。`char`、`short` 参加多数算术运算前会做整数提升；不同类型再按 usual arithmetic conversions 转换。逻辑运算结果是 `int` 类型的 0 或 1。`&&`、`||` 和条件运算符只求值必要的分支；位运算 `&`、`|` 不短路。`if`、`while`、`for` 以与 0 比较的结果控制路径。

## 原理与条件
求表达式应依次做：确认每个子表达式是否合法；按括号、优先级和结合性形成结构；应用提升与转换；最后追踪求值规则。优先级只决定分组，不自动规定两个操作数谁先求值。若一次完整表达式中对同一标量对象的修改彼此无序，可能是未定义行为。带符号整数溢出也是未定义行为；无符号运算按模 `2^N` 进行。题目若未给实现的位宽、`char` 符号性等条件，不应臆造唯一数值。

## 推导例题
设 C11，`int x=0, y=3; int r=(x!=0)&&(y/x>1);`。先求左操作数 `x!=0` 得 0；`&&` 短路，右侧 `y/x` 不求值，因此没有发生除零，`r=0`。若换成 `(x!=0)&(y/x>1)`，两个操作数都求值，出现整数除零，行为未定义，不能回答为 0。

## 易错点与反例
不要把“编译器给出某值”当成 C 语义保证。`i=i++` 不是固定先赋值还是先自增的问题，而是未定义行为。`unsigned int u=0; u-1` 的回绕有定义，但 `INT_MAX+1` 若以 `int` 计算则无定义。`switch` 的 `case` 不自动结束，缺少 `break` 会继续执行后继语句。

## 自查
