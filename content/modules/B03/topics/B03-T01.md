# 复杂度与递推分析

## 考查目标

- 解释本考点的数据结构或算法不变量。
- 手工列出中间状态，并据此核验结果。
- 区分适用前提、边界、时间复杂度与额外空间复杂度。

## 必要概念

渐进记号、循环计数与递推式。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

渐进分析先确定基本操作与输入规模。若语句执行次数为 c(n)，就化简 c(n)；顺序块相加、独立嵌套相乘、相关循环先求和。递归算法写 T(n)，再用递归树逐层累计。Θ 同时给上下界，O 只给上界，不能由 O(n²) 推出恰为 n²。

```text
count = 0
for i = 1 .. n-1:
    for j = 1 .. i:
        count++
# count = Σ(i=1..n-1)i
```

## 推导例题

上面各行贡献依次为 1,2,…,n-1。`c(n)=n(n-1)/2`，取最高次项得 Θ(n²)。对 `T(n)=2T(n/2)+n`，第 k 层有 `2^k` 个规模 `n/2^k` 的子问题，该层合计 n；共有 `log₂n+1` 层，故 Θ(n log n)，递归栈深度 Θ(log n)。

## 易错点与反例

`for(i=1;i<n;i*=2)` 是 Θ(log n)，不能只因“一个循环”判 Θ(n)。连续两个 Θ(n) 块仍为 Θ(n)，不是 Θ(n²)。
