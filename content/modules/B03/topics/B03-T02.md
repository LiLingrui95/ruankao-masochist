# 线性表、栈与队列

## 考查目标

- 解释本考点的数据结构或算法不变量。
- 手工列出中间状态，并据此核验结果。
- 区分适用前提、边界、时间复杂度与额外空间复杂度。

## 必要概念

顺序表、链表、LIFO、FIFO 与循环队列。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

顺序表把元素连续存放，按下标定位 O(1)，但在位置 i 插入要右移 n-i 个元素。单链表结点保存数据和 next；已知前驱时插入只改两条链。栈维护 top，队列维护 front/rear。循环队列采用模运算复用数组。

```text
# 容量 m，保留一个空槽
enqueue(x):
  if (rear+1)%m == front: overflow
  a[rear]=x; rear=(rear+1)%m
dequeue():
  if front == rear: underflow
  x=a[front]; front=(front+1)%m; return x
```

## 推导例题

令 m=5、front=3、rear=1，已有元素下标为 3、4、0，数量 `(rear-front+m)%m=3`。再入队一个元素后 rear=2，此时 `(2+1)%5=3=front`，队满且实际存 4 项。

## 易错点与反例

“链表插入 O(1)”隐含已持有前驱；若只给值，查找仍为 O(n)。若既用 `front==rear` 判空又允许 m 项全部占满，则满与空状态无法区分。
