# 字符串与模式匹配

## 考查目标

- 解释本考点的数据结构或算法不变量。

- 区分适用前提、边界、时间复杂度与额外空间复杂度。

## 必要概念

朴素匹配、前缀函数与 KMP。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

朴素匹配在每个对齐位置从头比较，最坏 Θ(nm)。KMP 先构造 `pi[j]`：模式前缀 `P[0..j]` 的最长相等真前后缀长度。失配时令 `j=pi[j-1]`，文本下标 i 不回退；每次回退使 j 下降，所以预处理和匹配均为线性。

```text
for i=1..m-1:
  while j>0 and P[i]!=P[j]: j=pi[j-1]
  if P[i]==P[j]: j++
  pi[i]=j
# 匹配阶段同样在失配时回退 j
```

## 推导例题

模式 `ABABAC`：pi 表为 `[0,0,1,2,3,0]`。计算最后 C 时先与 P[3]=B 失配，j 从3退到 pi[2]=1；再与 P[1]=B 失配，退到0；C≠A，故 pi[5]=0。文本 `ABABABAC` 中失配后无需回退 i，最终从下标2匹配。

## 易错点与反例

真前缀长度必须小于整个串长度。把 `j--` 当作 KMP 回退虽可能正确但会丢失线性保证；空模式与是否报告重叠出现也需约定。
