## 必要概念

树的度、高度、二叉树性质与遍历重建。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

树中结点度为孩子数；非空树 n 个结点有 n-1 条边。二叉树有 `n0=n2+1`。遍历：前序根左右、中序左根右、后序左右根、层序用队列。由“前序+中序”或“后序+中序”且键唯一可重建。Huffman 每次合并权值最小的两棵树，得到带权路径长度最小的前缀码树。

```text
build(pre, in):
  root = pre[0]
  k = position(root, in)
  root.left  = build(pre[1:1+k], in[:k])
  root.right = build(pre[1+k:], in[k+1:])
```

## 推导例题

前序 `ABDCE`、中序 `DBAEC`：根 A；左段 `DB` 对应前序 `BD`，B 在中序片段末端，所以 **D 是 B 的左孩子**；右段 `EC` 对应 `CE`，E 是 C 的左孩子。逐层得到后序 `DBECA`。重新对构造树做前序得 ABDCE、做中序得 DBAEC，双重回放验证。Huffman 权 2,3,7：先合 2+3=5，再合 5+7=12，码长为2,2,1，WPL=2×2+3×2+7×1=17。

## 易错点与反例

前序和后序通常不能唯一重建一般二叉树。Huffman 码字的 0/1 左右分配可以不同，但码长与 WPL 相同；编码不能是另一编码的前缀。
