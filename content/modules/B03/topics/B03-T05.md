# 平衡树、查找与散列

## 考查目标

## 必要概念

二分查找、BST、AVL 与哈希冲突。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

二分查找维护“答案若存在必在当前区间”的不变量。BST 左键小、右键大，中序有序；代价取决于高度。AVL 插入后从失衡祖先向上检查 LL/RR/LR/RL 并旋转。哈希把键映射到桶，冲突用拉链或开放寻址；平均 O(1) 依赖负载因子与分布。

```text
lo=0; hi=n-1
while lo<=hi:
  mid=lo+(hi-lo)//2
  if a[mid]<x: lo=mid+1
  elif a[mid]>x: hi=mid-1
  else: return mid
return -1
```

## 推导例题

在 `[3,8,12,17,21,30]` 查17：区间 `[0,5]`，mid=2 得12，排除 `[0,2]`；区间 `[3,5]`，mid=4 得21；区间 `[3,3]` 找到17，共3次比较。哈希容量5、h(k)=k mod5，键1、6、11都入桶1，拉链查11需沿链比较。

## 易错点与反例

混用 `[lo,hi]` 和 `[lo,hi)` 会漏端点或死循环。哈希 O(1) 是平均界；攻击性冲突可退化为 O(n)。AVL 平衡因子合格不等于整棵树高度恰相等。
