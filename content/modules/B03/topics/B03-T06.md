## 必要概念

图表示、BFS、DFS 与 DAG 拓扑序。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

邻接矩阵占 Θ(V²)，查边 O(1)；邻接表占 Θ(V+E)，适合稀疏图。BFS 入队时标记，按层扩展；DFS 进入顶点时标记并递归未访问邻点。Kahn 拓扑排序反复删除入度0顶点；若最终处理数小于 V，则图有环。

```text
Q = all vertices with indegree 0
while Q not empty:
  u=pop(Q); output u
  for each u->v:
    indegree[v]--
    if indegree[v]==0: push(Q,v)
```

## 推导例题

边 `A→C,B→C,C→D`，初始入度 A=0,B=0,C=2,D=1。若先取A，再取B，C入度依次降为1、0，随后输出C、D，得 A,B,C,D；先B也可得 B,A,C,D，说明拓扑序不必唯一。

## 易错点与反例

BFS 的最短边数结论只适用于无权图或等权图。无向边在邻接表出现两次，但复杂度仍写 Θ(V+E)。仅看“存在入度0顶点”不能证明整个图无环。
