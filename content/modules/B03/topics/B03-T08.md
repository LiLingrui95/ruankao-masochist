# 排序算法与稳定性

## 考查目标

## 必要概念

比较排序、稳定性、时间与空间权衡。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

稳定排序保持等键记录的原相对次序。插入排序对近乎有序序列快；归并排序稳定且最坏 Θ(n log n)，需 Θ(n) 辅助空间；堆排序原地且最坏 Θ(n log n)但不稳定；快速排序平均 Θ(n log n)、最坏 Θ(n²)。

```text
merge(L,R):
  while both nonempty:
    if L[i].key <= R[j].key: take L[i]  # 等键先左，保持稳定
    else: take R[j]
  append remainder
```

## 推导例题

对 `(2,a),(1,x),(2,b)` 分治：左半归并为 `(1,x),(2,a)`，再与 `(2,b)` 合并；等键时先取左项，结果 `(1,x),(2,a),(2,b)`。若相等时先取右项，a、b 次序颠倒。

## 易错点与反例

“交换次数少”不等于稳定。随机主元降低快速排序退化概率但最坏界仍 Θ(n²)。比较排序的一般最坏下界为 Ω(n log n)，计数排序靠键域信息绕过比较模型。
