# 分治与二分

## 考查目标

- 解释本考点的数据结构或算法不变量。
- 手工列出中间状态，并据此核验结果。
- 区分适用前提、边界、时间复杂度与额外空间复杂度。

## 必要概念

拆分、递归求解、合并与单调答案。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

分治包含划分、递归求解、合并。二分答案不是查数组，而是在答案域上利用单调判定 `feasible(x)`；循环必须维护一端满足/另一端不满足或“答案始终在闭区间”这一不变量。

```text
# 求最小满足 feasible 的整数
lo,hi = known_range
while lo<hi:
  mid=lo+(hi-lo)//2
  if feasible(mid): hi=mid
  else: lo=mid+1
return lo
```

## 推导例题

求最小整数 x 使 x²≥30，初始 `[0,30]`：mid15满足→`[0,15]`；mid7满足→`[0,7]`；mid3不满足→`[4,7]`；mid5不满足→`[6,7]`；mid6满足→`[6,6]`，答案6。

## 易错点与反例

若判定序列为真、假、真便不单调，二分会跳过答案。`(lo+hi)/2` 可能溢出。合并步骤若反复在线性数组中间插入，会使本应线性的 merge 退化。
