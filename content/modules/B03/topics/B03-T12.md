# 回溯与算法综合案例

## 考查目标

- 解释本考点的数据结构或算法不变量。
- 手工列出中间状态，并据此核验结果。
- 区分适用前提、边界、时间复杂度与额外空间复杂度。

## 必要概念

解空间树、选择、约束、撤销与剪枝。本节所有复杂度均以输入规模为参数；涉及图时用 V、E，涉及文本时用 n、m。

## 原理与条件

回溯按解空间树深搜：选择→约束检查→递归→撤销。可行性剪枝排除非法前缀，上界剪枝排除不可能优于当前最优的分支。撤销必须恢复所有共享状态。去重常先排序，并只在同一递归层跳过相同值。

```text
dfs(start,sum,path):
  if sum==target: record(path); return
  for i=start..n-1:
    if i>start and a[i]==a[i-1]: continue
    choose a[i]
    dfs(i+1,sum+a[i],path)
    undo a[i]
```

## 推导例题

集合 `{1,2,3}`、目标3：从空路径选1，再选2得到 `{1,2}`；撤销2后选3使和4，因元素为正可剪；撤销1，从根选2后再选3也超出；根选3得到 `{3}`。解为两组。

## 易错点与反例

“当前和超过目标”仅在后续元素非负时安全；若有 -5，和4仍可能回到目标。忘记撤销 used、路径或累计和会污染兄弟分支。指数最坏界不会因剪枝自动消失。
