## 考查目标
能从完整技术短文提取主旨、条件、因果、指代和术语含义，而非仅记忆孤立词汇。

## 必要概念
技术英语常用限定词：may 表示可能或许可，must 表示规范性必须，unless 引出例外条件。代词 `it/they/this` 要回指最近且语义相容的实体。被动语态常突出对象而非执行者。网络语境中的 request、response、method、representation 和 cache 都需结合句子判断。

## 原理与条件
阅读顺序是先找每段主题句，再圈出条件和转折，最后解释术语。不要把相关句子自行补成因果。标准文本中的大写关键词有规范含义，而普通说明文里的小写 must 也可能只是作者强调，需识别文体。

## 推导例题
原创短文："A client sends a request through an intermediary. The intermediary may reuse a stored response only when the applicable caching rules permit the reuse. Reuse can reduce latency, but stale metadata can make the response unsuitable. Therefore, the client still needs a way to validate a stored representation." 主旨是缓存复用受规则和新鲜度约束。原句若写作 `permit it`，`it` 指前述复用行为，不是 stored response；这里改用 `permit the reuse` 消除歧义。`therefore` 引出即使缓存降低延迟仍需验证的结论。

## 易错点与反例
`may` 不能一律译为“五月”；`representation` 在 HTTP 中不是“代表人物”。看到 reduce latency 不能推断缓存总是安全。题目问作者明确陈述时，不要选择常识上可能正确但文中未支持的选项。

## 自查
能否为答案标出原句证据？能否说明限定词改变了结论强度？
