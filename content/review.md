# 三单元内容核验

日期：2026-09-24。内容版本：1.0.0。审查方式：作者自审、官方语言文档对照、示例实际执行；尚未经过独立专家或真实学习者试读。

| 单元 | 知识目标 | 题型覆盖 | 核验重点 |
| --- | --- | --- | --- |
| CSF-01 程序与数据 | 输入、处理、输出；赋值与显示 | 4 选择、1 简答、1 代码填空 | 区分问题模型与键盘输入，限定脚本语境；输出不限于 print |
| CSF-02 跟着程序走一遍 | 状态跟踪、条件边界、循环累计 | 4 选择、1 简答、1 代码填空 | 不把赋值当自动更新公式；`>` 与 `>=`；range 不含终点 |
| CSF-03 数组、索引与遍历 | 元素、索引、长度、边界 | 4 选择、1 简答、1 代码填空 | Python list 与 C# 数组明确区分；固定长度不等于只读；空集合边界 |

18 题均为原创基础练习，不标注年份真题或考试评分。12 道选择题均有唯一参考选项及四个选项的解释；6 道主观题各有三个自评要点。代码填空要求同时写出输出与依据，允许参考说明中列明的等价表达。

课程共 9 段 Python 示例，输出通过自动测试核验；4 段 C# 示例由本机 PowerShell `Add-Type` 编译并调用，分别输出 `36`、`pass`、`6`、`3 / 30`。题库中带 `test_output` 的全部 Python 片段通过自动执行核验。未执行用户提交的代码。

官方语言规则来源及定位见 `pack.json` 的 sources；每个单元和题目均保留 source_ids。来源用于核验语言规则，不意味着课程或题目由官方编写。

待真实用户反馈：是否过于基础、是否需要减少 Python/C# 对照、4—5 分钟小节是否合适、自评要点是否容易判断。预计时间仅为任务编排参考，不是测量结论。
