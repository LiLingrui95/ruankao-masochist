# 最小编写模板

完整字段定义以 `content/schemas/` 为准；模板中的示例 ID 不得直接作为新题发布。

## 考点正文

```markdown
# 考点标题

## 考查目标
描述学习后能独立完成的任务。
## 必要概念
首次出现术语写中文解释与 English term。
## 原理与条件
明确公式、算法或定义的适用条件。
## 推导例题
给定输入 → 中间状态 → 结果 → 验证。
## 易错点与反例
给出条件改变后的失败例子。
## 自查
一个不用查看答案即可尝试的问题。
## 关联练习
稳定题号及训练目的。
## 出处
source ID、定位与使用方式。
```

## 题目要求

选择题四个稳定英文选项 ID；正确答案唯一，每个干扰项说明错因。主观题按明确的语义要点自评，不能用“结论正确”作为唯一标准。

案例材料描述业务实体、约束、输入、代码或图。子问引用材料但不包含答案；答案按子问编号展开推导。题目所用附件位于所属目录 `assets/`，`assets[].path` 相对于 `content/`。

## 验证记录

每个板块 `review.md` 至少记录：内容范围与实际数量、实际打开的主要来源、答案核验方法、执行命令与结果、未验证事项、返修记录。若 `verify.py` 只检查 JSON 结构，不得把它描述为答案正确性验证。
