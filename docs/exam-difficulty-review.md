# 真题难度校准与单元重设

调研日期：2026-09-24。结论：已有 Python/C# 经验的学习者应直接进入考试专题，遇到知识缺口再补充。原版输入输出、简单循环和索引课程可以作为选读，但不适合作为主线三单元。

## 证据与可靠性

1. [考试大纲出版信息](https://www.tup.tsinghua.edu.cn/bookscenter/book_07814301.html)：清华大学出版社，编者为全国计算机专业技术资格考试办公室。用于确认资格与大纲来源，不把出版页当成完整最新机考规则。
2. [2022 下半年综合知识公开题干](https://www.cnitpm.com/pm1/140332.html)：抽查第 1—6、24—28 题，涉及指令体系、可靠性、浮点、补码、同步与存储计算。为第三方整理的历史试卷，题干有转录错误，网站答案不是官方评分标准。
3. [2022 下半年应用技术公开题干](https://www.cnitpm.com/pm1/140456.html)：试题二要求从业务约束推导关系结构；试题四要求补全 C 算法、分析复杂度并跟踪堆调整。该页代码图片与文字参考答案有明显转录问题，未直接导入其答案。
4. [2023 上半年应用技术试题二](https://www.cnitpm.com/pm1/147958du2jp3exca.html)：采购场景涉及多个实体、联系与新增业务需求，能力要求超过背诵主键定义。
5. [出版社下午辅导书说明](https://www.tup.tsinghua.edu.cn/bookscenter/book_07120301.html)：覆盖 DFD、数据库、UML、算法和面向对象程序设计，与上述样本交叉核对。

检索中的部分 2024/2025 页面只有“考后更新”或混用往年题，已排除；不宣称核验了完整最新试卷，也不根据少量样本推算准确分值占比、通过率或押题概率。官方考试站本轮未成功抓取，因此不更新考试时长或选考规则。

## 能力差距与新课程

| 旧版主要训练 | 新版训练目标 | 当前单元 |
| --- | --- | --- |
| 看出一次赋值或乘法结果 | 明确位宽和模型，分步骤计算并识别适用条件 | 01 计算机系统与性能计算 |
| 跟踪简单循环 | 复杂度、栈与树、二分不变量、动态规划状态 | 02 数据结构与算法分析 |
| 区分元素与索引 | 从业务约束推导键、依赖、范式、联系与查询 | 03 数据库与关系建模 |

这三单元是基础考试专题的试点，不能代替完整备考。每节采用“考什么 → 必要概念 → 推导例题 → 易错条件 → 自查”，题目分为考点应用与综合推导。难度标注是编辑判断，尚无真实答题统计校准。

24 题全部重新原创，保留来源与对标能力；更换场景、数据和问题结构，不复制整套试卷。代码练习以 C 和 SQL 为主，Python 仅用于少量辅助验证。主观题依然自评，不生成虚假的考试分数。

## 后续单元顺序

4. 操作系统：进程线程、PV 同步、死锁、分页与磁盘。
5. 程序语言与编译：C 阅读、参数传递、编译阶段、表达式。
6. 算法进阶：排序、堆、图、贪心、分治、动态规划综合。
7. 软件工程与测试：过程模型、内聚耦合、覆盖、复杂度度量。
8. 结构化分析：DFD 平衡、数据字典、加工逻辑与案例。
9. 面向对象与 UML：关系、多重度、用例、类图与状态。
10. 设计模式与选考语言：Java/C++ 方向在真实样题试做后决定。
11. 网络与安全：地址划分、协议、密码与认证。
12. 标准、知识产权、专业英语与综合模考。

后续单元尚未制作；不把目录视作已覆盖考纲。优先依据本次三单元表现确认学习节奏，再逐步补齐。
