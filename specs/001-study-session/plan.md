# 技术方案

Python/FastAPI 提供本地服务，Jinja2 输出页面外壳，原生 JavaScript 管理四个工作视图；SQLite 保存单用户状态。应用绑定 127.0.0.1:8765。没有外部字体、脚本或联网运行依赖。

内容采用 `content/pack.json` + Markdown 课程，按小节展示；18 题带来源、解析、要点和版本。渲染禁用原始 HTML，答案在提交或主动揭示前不通过题目接口下发。

小型应用只需一个 SQLite 状态记录，事务读取—修改—写回；状态内部保留独立 attempts、exposures、drafts、notes、unit progress、session、feedback。服务端负责题目校验、评分、幂等及统计；前端不伪造评分。每次修改在事务内完成，不接受客户端覆盖全量状态。

各类写入为专门 API：开始会话、阅读位置、草稿、提交、揭示、自评、笔记、反馈、先修跳过。多次重试以 submission_key 去重。备份为含内容快照的 JSON，恢复只接受当前已知且内容一致的版本；此 P1 无跨版本迁移，拒绝不匹配包且不改现有记录。恢复前保留完整旧备份。

失败时前端显示错误并保留用户输入。草稿、笔记临时副本放入浏览器恢复缓存；永久状态始终以服务端为准。自动保存短延迟串行执行，避免旧响应覆盖新输入。

视觉：深墨蓝侧栏、明亮纸白阅读区、青蓝主操作、少量橘色标注。宽屏保留课程目录与学习正文的稳定关系，小屏导航与内容纵向排列。使用本机中文字体，正文 16px 以上，支持键盘和 reduced-motion。
