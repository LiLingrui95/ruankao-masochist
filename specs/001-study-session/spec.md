# 001 · 三单元学习试点

日期：2026-09-24。用户已授权制作前三单元与简要平台，本 feature 覆盖 P0 内容制作和 P1 可用流程。

## 范围

3 个完整课程单元、18 道原创题（每单元 4 选择、1 简答、1 代码填空）。首页直接开始学习，四个导航为今日、学习、练习、回顾。课程分小节阅读，保存当前位置；练习保存草稿，提交后反馈，主观题按要点自评；提供笔记、错题再练、记录、备份恢复和试用反馈。

不实现 P2 间隔调度、完整周总结、考试模考、公网发布或跨设备同步。错题再练仅按最新结果筛选，不声称是到期复习。

## 用户故事与验收

- 新用户选择 10/25/45 分钟，获得有限任务；10 分钟采用一个约 4—5 分钟小节与最多两道短题，总估时不超过所选时长。AC-01。
- 用户读完小节、离开后能回到原处；笔记与草稿出现服务确认的保存状态。AC-02/19。
- 选择题可改选后提交，幂等重试不重复记账。AC-03/04。
- 简答/代码先提交原文再逐项自评；未自评保留待评价；重写为新尝试。AC-09/10。
- 先看答案立即记入揭示历史，当天重做标为参考后作答，不混入独立首答。AC-08/24 的 P1 部分。
- 学习单元先修有明确提示，可以主动跳过并保存选择。AC-21。
- 备份包含课程、题目及学习记录；恢复先验证再显示摘要，确认替换时留存旧备份。AC-16/17。
- 笔记和答案只按文本展示，Markdown 禁止原始 HTML。AC-20。
- 用户可以在页内记下反馈并导出；不自动发送给任何人。

完成以 API 集成测试、内容代码核验、浏览器实际交互和恢复检查为依据。真实用户试读由交付后的用户进行，不能提前标为通过。
