## 自审与迭代

1. 修复主观题暂不自评时仍继续下一题的问题，保留待自评入口，并允许回到较早的未评记录。
2. 为提交后隐藏操作补上明确的 hidden 样式，避免 CSS 展示规则覆盖浏览器默认行为。
3. 首页增加上次阅读／答题位置入口，首次加载恢复已选学习时长。
4. 限定会话内的阅读推进，避免自由阅读被已完成任务送回首页。
5. 检查题重练创建新答题草稿，同时保留原始作答和答案揭示记录；增加回归测试。

## 边界与后续

这一版是个人本机试点。代码题不在线执行；主观题为自评。尚未实现真题导入、到期间隔复习、完整周总结、账号与跨设备同步、公网部署。备份仅恢复当前一致的内容版本。

用户先试用 1—3 次，每次 10—25 分钟；反馈课程难度、最卡的一步和是否愿意再次打开。用户反馈是进入后续内容与 P2 功能的依据，未提前记为验收通过。
