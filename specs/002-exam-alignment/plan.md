# 002 技术方案

保留原有 FastAPI、SQLite、原生 JavaScript 结构。内容包改为 v2，使用 SE-* ID；原包放入 content/archive/pack-v1.json，原 Markdown 保留。

服务端区分当前课程和全部可检索内容。首页统计与每日任务只使用当前课程；历史作答、笔记、草稿通过旧 ID 继续解析。旧会话不作为新版今日任务返回，但不在启动时删除历史状态；下次创建会话按正常流程替换会话指针。

备份 schema 2 同时保存新旧包及课程，兼容 schema 1 的原版备份。升级前导出完整原备份；不直接重写用户答题历史。

题目增加 section_index、difficulty、exam_anchor、language。任务按“对应小节→该节练习”交错生成，超预算时停止，避免跳过未读小节却安排其练习。

前端统一使用 resultBadge 渲染结果。正确为深绿文字、浅绿背景和 ✔；错误为深红文字、浅红背景和 ❌；待自评为灰色时钟符号。反馈区域使用 role=status、键盘焦点与滚动定位，题目列表及历史共用标识。

测试重点：旧数据兼容、任务顺序、答案计算与 SQL、算法独立模型的边界验证、浏览器视觉检查。无需新增框架或在线代码沙箱。
