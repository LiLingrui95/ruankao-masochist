# 004 按学习目的安排任务

用户选择方案 A，替换首页的 10/25/45 分钟选项；保持现有知识库、题库与作答反馈。

## 行为与验收

- 学新知识：继续未完成学习组；新组安排下一未读小节和最多三道配套题，已读但未练的题可补练。预计用时仅作提示。
- 错题再练：使用最新答错或不确定的题目，每组最多五题；必须重新作答，保留历史；没有错题时明确提示。
- 单元自测：选择已阅读或已作答的单元，最多五题，尽可能覆盖不同小节和题型；每题保留现有反馈与主观题自评，全部完成后汇总待巩固知识及讲解入口，不声称考试分数。
- 切换模式或自测单元立即更新任务标题、题数、预计用时。预览不开始任务，也不清除草稿。
- 点击开始才激活任务；各模式/自测单元的未完成队列与草稿独立保存，切回可继续。
- 保留旧 session API 和旧备份兼容；新增状态必须进入备份校验；不改动用户已有答案。

## 执行计划

1. 实现共用任务规划、预览、开始/恢复与独立草稿；用 API 测试核验切换、空态、重复练习、备份。
2. 替换首页选项并增加单元选择、任务预览和完成回顾；沿用视觉风格与正确/错误标识。
3. 跑回归测试，在隔离数据中验证浏览器三种模式；备份生产数据后加载新版。
