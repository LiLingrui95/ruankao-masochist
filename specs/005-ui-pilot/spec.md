# 005 两页 UI 试点

本阶段只改造“今日学习”首页与单个学习页的共享界面，不扩展练习、真题、回顾等业务页，也不加入缓存或数据库图。

## 验收范围

- 共享布局采用浅色纸面、深色文字和青绿色自绘 SVG 图标，不依赖 CDN。
- 宽度 `>=1100px` 使用完整侧栏；`720–1099px` 使用紧凑侧栏，保留图标和文字；`<720px` 使用可折叠顶栏菜单，支持 Escape 关闭并把焦点还给菜单按钮。
- 跳过链接直接聚焦主内容，不改变 hash；当前导航使用 `aria-current="page"`。
- 保存状态在全部尺寸下可见；保存失败时可点击重试。
- 首页遵循“选择学习目的 → 选择自测单元（如需）→ 预览 → 开始”的单一路径，保留三种模式、`previewSequence` 与 `routeSequence` 防竞态逻辑。
- 预览不创建任务、不清除草稿；只有点击开始才激活任务。模式及自测单元各自恢复独立队列和草稿；空态不可开始；较慢的旧预览响应不可覆盖新选择。
- 首页预览默认展示前三个剩余任务，其余任务可展开；“继续上次”与当前模式的预览、开始操作有清晰区分。
- 学习页突出当前小节，正文宽度不超过 760px；目录可键盘访问，并继续使用现有 hash 路由。
- Markdown 文本、`##` 分节顺序、section index 和 ID 保持不变；目标、易错、自查等语义样式由展示层增强。
- 数组二分图解仅出现在 `SE-02` 的 section index 2。固定数组为 `[4, 11, 19, 28, 36, 47, 59]`，支持目标 47 和 35、上一步、下一步和重置，不自动播放；切换目标时重置。
- 目标 47 在第二次比较命中；目标 35 最终显示 `low=4, high=3` 且无 `mid`，返回 `-1`。图解步骤只保存在页面内存。
- 图解把比较与边界更新拆成不同步骤。成功路径为 `28 → 47`，失败路径为 `28 → 47 → 36 → 空区间`；首尾方向按钮按状态禁用。
- 图解控件可由键盘操作，步骤变化通过可感知的状态文本播报，并用文字标签而非仅用颜色表达 `low`、`mid`、`high` 和返回值。
- 图解不调用 `/api/read`、`/api/submit` 等完成接口；刷新或重新进入页面都回到目标 47 的初始步骤。
- `B03-T09` 提供“数组二分补充图解”入口，并明确它不同于当前考点的二分答案正文。
- 任务题号完成状态来自当前 `session.tasks[].done`；自由练习沿用历史作答标记。

## 兼容约束

- 不修改 API、SQLite 数据、备份 schema、草稿格式或内容 Markdown。
- 不重启生产服务；验证使用 `D:\study\data` 下的隔离临时目录。
- 既有 API 回归必须通过；浏览器交互使用隔离数据库，不写生产学习记录。
